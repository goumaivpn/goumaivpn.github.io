第一章 下载前的准备工作

1.1 设备兼容性检查

索尼设备涵盖Android手机、Windows笔记本等多条产品线，安装前需确认系统版本：
- Android设备：需运行Android 5.0及以上（如Xperia 1 IV/5 IV等新型号默认兼容）
- Windows设备：推荐Win10/11（VAIO或索尼商务本需检查.NET Framework支持）
小技巧：在Android设置中点击「关于手机」查看系统版本；Windows用户按Win+R输入winver查询。

1.2 官方渠道获取安装包

务必通过Clash官方GitHub仓库（如Clash for Windows）下载，避免第三方修改版的安全风险。针对索尼设备推荐：
- Clash for Android：APK文件约15MB，支持索尼手机的分屏模式
- Clash for Windows：EXE安装包，适配索尼笔记本的高DPI屏幕

第二章 分步安装指南

2.1 Android设备安装流程（以Xperia为例）

  1. 允许未知来源安装：进入「设置→应用和通知→特殊应用访问」，启用「安装未知应用」权限
  2. 安装APK：通过索尼文件管理器找到下载的APK，点击后按提示完成安装
  3. 首次运行配置：授予VPN连接权限（关键步骤！否则无法代理流量）

2.2 Windows设备安装流程（VAIO/Sony笔记本）

  1. 双击EXE安装包，若出现SmartScreen警告，点击「更多信息→仍要运行」
  2. 安装路径建议选择非系统盘（如D:\Clash），避免权限问题
  3. 安装完成后，在开始菜单生成快捷方式，右键「以管理员身份运行」

注：索尼笔记本若遇到驱动签名问题，需在BIOS中临时禁用Secure Boot

3.1 初始设置向导

FAQ

Mellow 的 TUN 模式与系统代理有何区别？
TUN 模式拦截系统 IP 层流量，实现全局代理，而系统代理通常只影响支持代理的应用。TUN 更适合游戏、视频和全局科学上网场景，保证所有流量通过节点，提高稳定性和速度。
VMess AEAD 加密如何确保数据传输安全？
AEAD 加密可防止数据篡改、重放攻击和流量特征泄露。在高封锁环境中保证节点可用，提升数据安全和连接稳定性，降低被检测风险，确保长期安全访问体验。
Netch 的全局代理与规则代理有何不同？
全局代理将所有流量都通过节点转发，而规则代理只针对指定 IP、端口或应用。全局代理适合游戏和全局科学上网，规则代理适合优化带宽和分流特定流量。
Mellow 的 TUN 模式与系统代理有何区别？
TUN 模式直接拦截 IP 层流量，实现全局代理，而系统代理通常仅影响支持代理的应用。TUN 更适合游戏、视频或全局科学上网场景，确保所有流量经过代理节点。
Hysteria2 的 QUIC 协议相比 TCP 有什么优势？
QUIC 协议基于 UDP，减少了握手延迟，支持多路复用和拥塞控制优化。Hysteria2 利用 QUIC 提供更低延迟、更高稳定性的网络连接，尤其适合高延迟或丢包环境。
V2Ray 如何使用 WebSocket 传输？
在 V2Ray 配置文件中将传输方式设置为 ws，即启用 WebSocket 模式。结合 CDN 和 TLS，可实现安全高速的代理链路。WebSocket 常用于伪装成 HTTPS 流量，从而降低被识别风险。
V2Ray 如何实现分流规则？
V2Ray 使用 routing 模块实现分流，可根据目标域名、IP、端口或协议类型决定流量走向。用户可自定义多个 outbound，并通过规则实现国内直连、国外代理等智能路由功能。
如何配置 Clash 的 GEOIP 分流？
Clash 支持使用 GEOIP 数据库进行区域分流。用户在规则文件中添加 `GEOIP,CN,DIRECT` 可使国内流量直连，而国外流量走代理，从而提升整体网络性能。
Sing-box 的 DNS 模块如何工作？
Sing-box 内置 DNS 模块，支持 fake-ip 模式和纯直连模式。它可根据规则选择不同的上游 DNS 服务，从而实现国内外域名智能分流，减少访问延迟。
V2Ray 的传输协议选择对性能有何影响？
V2Ray 支持 TCP、WebSocket、gRPC、QUIC 等多种传输协议。不同协议在延迟、抗封锁和吞吐量上差异明显。用户可根据网络环境选择最优协议，以获得稳定且高速的连接体验。
